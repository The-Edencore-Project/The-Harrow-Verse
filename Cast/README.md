📁 Harrowverse Character Index

This folder contains all character profiles for the Harrowverse. Each character is stored in its own markdown file for clarity, modularity, and future expansion. Files use two‑digit numbering for stable GitHub ordering.

🌿 Purpose

This directory acts as the master index for every character, archetype, and entity in the Harrowverse. Profiles are kept lightweight and emergent, allowing characters to grow naturally over time.

🧭 Structure

Each file includes:

A short profile

Personality notes

Role in the Harrowverse

Emergent traits (as they develop)
